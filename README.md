# Municipalit-

Application de gestion municipale — Backend Spring Boot + Frontend Angular.

## Structure

```
├── backend/    # Spring Boot (Java 17, MySQL, JWT)
└── frontend/   # Angular 17
    └── baladiati-frontend/
```

## Démarrage

### Backend
```bash
cd backend
mvn spring-boot:run
# http://localhost:8080
```

### Frontend
```bash
cd frontend/baladiati-frontend
npm install
npm run start
# http://localhost:4200
```
